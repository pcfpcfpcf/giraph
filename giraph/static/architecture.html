SCENE 01 / 08 · THE FUNDAMENTAL THREAT

The Agent Vulnerability: Attention Conflation

LLMs cannot structurally differentiate control flow instructions from retrieved external data. An adversary in an email thread or invoice injects commands that hijack agent execution.

SCENE 02 / 08 · THE GOVERNING INVARIANT

The GIRAPH Axiom: Selection vs Authoring

Security by construction: we do not detect attacks by heuristics. We enforce an invariant boundary separating trusted control flow from untrusted dynamic values.

“Untrusted data may SELECT. It may never AUTHOR.”
Structure comes from the trusted plan. Values may come from anywhere. An injection is inert because there is no channel through which it can act.
STRUCTURE (TRUSTED & FROZEN)
• Verified Plan Graph topology
• Pre-authorized finite state branches
• Abstract Effect Envelope
• Denied effects & restricted destinations
✓ IMMUTABLE AT RUNTIME
KINETIC DEFENSE BARRIER
VALUES (DYNAMIC & UNTRUSTED)
• Email bodies, web HTML, API payloads
• Injected attacker prompt strings
• Dynamic identifiers & query text
• CAN ONLY SELECT PRE-APPROVED ENUMS
× FORBIDDEN FROM ADDING GRAPH NODES

SCENE 06 / 08 · DETERMINISTIC OUTCOMES

The Four Verdicts: Deterministic Action Resolution

Every candidate action resolves into one of four verified outcomes. Unsafe branches are intercepted or rewritten with zero utility loss on benign tasks.

[ALLOW]
Conforms strictly to a verified node, or represents an envelope-conforming divergence.
risk: 0.00 | conf: 1.00
Tool call executes cleanly.
[BLOCK]
Requires authority the envelope never granted, driven by untrusted external content.
risk: 0.95 | conf: 0.85
Tool dropped. 0 data leaked.
[REWRITE]
Unsafe branch pruned, safe subplan preserved (e.g. email_send → email_draft).
risk: 0.20 | conf: 0.90
Subplan safely mutated.
[ESCALATE]
Checker returns unknown or irreversible human confirmation is strictly mandatory.
risk: 0.50 | conf: 0.70
Human supervisor prompted.
SCENE 07 / 08 · LIMITS & FAIL-SAFES

Guarded Replanning & 4 Honest Boundaries

Replanning is the most dangerous attack surface in agent defense. GIRAPH enforces mathematical envelope contraction and transparently documents its structural boundaries.

THE REPLAN GUARD INVARIANT
If replanning is triggered during long-horizon tasks, GIRAPH strictly enforces two iron laws:
RULE 1
Replan only from original request + abstract facts (never raw untrusted content).
RULE 2
A replan may ONLY NARROW the envelope. It may NEVER widen it.
4 HONEST STRUCTURAL LIMITS
1. Malicious Principal: User commanding an attack directly bypasses planner.
2. Over-generalized Envelopes: Vague user goals produce wide envelopes.
3. Search Depth Bounds: Long-horizon graph exploration limits.
4. Semantic Masquerading: Actions sharing identical effect profiles.
